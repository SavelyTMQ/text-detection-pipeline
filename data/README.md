2. Распакуйте в эту папку


## Про датасет

Total-Text — сложный датасет для scene text detection:
- 1555 изображений
- 3 ориентации текста: горизонтальная, многонаправленная, **изогнутая**
- Пиксельные маски для сегментации + bbox разметка
